# Cloudflare 注册与配置清单（照着做，5 分钟）

## 步骤 1：注册 / 登录 Cloudflare

打开你截图那个页面（https://dash.cloudflare.com/login），**点 `GitHub` 图标**即可。

- 你已有 GitHub 账号（`xjhod`），点一下就完成注册 + 登录，不用填邮箱密码
- 选免费计划（Free），**不需要绑信用卡**
- 注册完会进控制台

## 步骤 2：创建 Pages 项目（名字必须完全一致）

控制台 → 左侧 `Workers & Pages` → `Create application` → `Pages` → 选 `Connect to Git` 或 `Upload assets`

> ⚠️ **项目名必须填 `ketzxt-api`**（对应部署命令的 `--project-name=ketzxt-api`）
> 项目名全局唯一，若被占用就换一个（如 `ketzxt-api-2`），然后告诉我新名字。

选 `Upload assets`（纯静态，不连 Git —— 我们的静态站留在 GitHub Pages，这里只放 API）。

## 步骤 3：配置 API Key（Environment variables）

`Workers & Pages` → 点进 `ketzxt-api` → `Settings` → `Environment variables` → `Add`

| 名称 | 值 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | `sk-a83…`（用你「自动化转换」项目 .env 里那个 DeepSeek Key） | 文本评分，必需 |
| `SILICONFLOW_API_KEY` | 从 https://cloud.siliconflow.cn 复制 | 语音转写，可选但强烈建议 |

> 💡 部署脚本会告诉你这两个 Key 是否生效：
> `llm:true` = DeepSeek OK，`asr:true` = SiliconFlow OK

> 🔒 **安全提醒**：仓库是**公开**的，Key 绝对不能写进任何入库文件（文档、示例、
> 注释都不行）。只放在 Cloudflare 控制台的 Environment variables 里。
> 一旦 Key 进了 git 历史，即使删掉文件也仍然泄露 —— 必须去控制台吊销该 Key 并重建。

**注意**：环境变量默认只在 Production 环境生效，Preview 不继承 —— 我们只用 Production，无需改。

## 常见问题

**Q：注册时要求绑信用卡？**
A：免费计划不需要。注册后可能会推荐付费套餐，选 Free 即可。

**Q：`wrangler login` 打不开浏览器？**
A：在你自己的终端里执行（不是通过我）。也可以用 API Token 方式：
控制台 → My Profile → API Tokens → Create Token → 模板选 "Edit Cloudflare Workers"，
然后 `export CLOUDFLARE_API_TOKEN=xxx`，我再用 token 部署。

**Q：项目名 `ketzxt-api` 被占用？**
A：换一个（如 `ketzxt-api-kid`），然后告诉我，我同步改 `deploy-pages.sh` 和 GitHub Secret。

**Q：为什么不用 Workers（workers.dev）？**
A：实测 `workers.dev` 在国内被 DNS 污染（直连 21 秒超时），`pages.dev` 正常。
详见 `worker/README.md` 的「部署前必读」。
